# politica-privacidad-app
Política de Privacidad

Última actualización: 2026

Esta aplicación ha sido desarrollada con el propósito de facilitar la conexión y gestión de dispositivos de red MikroTik desde un dispositivo móvil.

La aplicación no recopila, almacena ni comparte información personal del usuario.

Información recopilada

Esta aplicación no solicita ni recopila datos personales como:

Nombre

Correo electrónico

Ubicación

Contactos

Archivos del dispositivo

Uso de la red

La aplicación utiliza únicamente la conexión de red del dispositivo para permitir que el usuario establezca comunicación con routers MikroTik dentro de su red local o remota.

Compartición de información

La aplicación no comparte información con terceros.

Seguridad

La aplicación no almacena datos del usuario ni información sensible en servidores externos.

Cambios en esta política

Esta política de privacidad puede actualizarse en futuras versiones de la aplicación. Cualquier cambio será reflejado en esta misma página.

Contacto

Si tienes preguntas sobre esta política de privacidad, puedes contactar al desarrollador.
